# S8N Janus recovery collection plan

> For agentic workers: implement and review the independent model adapter and collector tasks, then validate the integrated campaign before production.

Goal: generate a first complete pass of recovery trajectories with the original S8N checkpoint for 10,819 R2R and 19,996 English-guide RxR15 training episodes, split over the two authorized servers.

Architecture: standalone `s8n_dagger` package imports the immutable evaluated S8N source. A persistent model subprocess proposes actions transactionally, and commits only the executed response. Habitat owns the reference-waypoint oracle, Janus recovery policy, pre-action RGB capture, durable records, and compatible executed-action training exports.

Spec: the user's October 27 request and explicit choice, "Match Janus recovery behavior". This is recovery imitation, not oracle-label DAgger training. Keep oracle labels in raw records for future use, but export executed actions for current S8N training.

## Branch comparison correction

The user requested comparison with `dagger_s8n_test`; fetched commit `d8c408f007299ad7eab8b74cbf0f74ffff493e10`. This exposed our initial waypoint error-counter reset as a deviation from Janus. A regression test demonstrated the difference; protocol v2 preserves the counter. The early local v1 collection was stopped and remains a separately identified pilot, excluded from production. New v2 outputs are required because resume contracts must never be altered in place. Keep immediate takeover using verified rollback (Janus), rather than the comparison branch's deferred takeover. Keep both datasets, cap675 and Janus's original clean-detour save policy; the comparison branch is an R2R-only experiment with max183 saved steps and a clean-episode exclusion.
